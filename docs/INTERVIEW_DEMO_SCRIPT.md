# Interview Demo Script

1. Open the deployed app.
2. Click demo profile or create a profile.
3. Upload a resume.
4. Explain that the app extracts skills and uses them to generate role-specific searches.
5. Fetch jobs.
6. Show ranked job cards.
7. Explain match score, missing skills, risk flags, and job quality score.
8. Click Apply on Website to show that users are taken to the original posting.
9. Download a prep packet.
10. Show analytics and learning roadmap.

Suggested explanation:

> I built this as a review-first job intelligence platform. The goal was not to mass apply, but to help users prioritize high-fit roles using resume parsing, job ingestion, filtering, ranking, and dashboard analytics. It demonstrates Python, NLP-style matching, data normalization, Streamlit, SQLite, testing, and deployment readiness.
