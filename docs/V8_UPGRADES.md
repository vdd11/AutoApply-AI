# v8 Upgrade Notes

This release focuses on product polish and usability.

## Added

- Public careers-page crawler for job links
- Saved search history
- Apply-link click tracking
- ATS keyword coverage
- Resume tailoring bullet suggestions
- Interview prep questions
- Follow-up message generator
- Improved dark-mode styling
- Richer prep workflow tab
- Stronger deployment README

## Why this matters

The app now behaves more like a deployable product than a local script. A user can create a profile, upload a resume, fetch jobs, review job-card explanations, open the job site, and prepare application materials from one dashboard.
