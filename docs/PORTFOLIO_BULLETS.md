# Resume Bullets

- Built a deployable AI-powered job intelligence platform that parses resumes, ingests live job postings, ranks opportunities using NLP-based matching, and tracks application status through an interactive Streamlit dashboard.
- Designed a normalized SQLite data model for resumes, jobs, job scores, applications, and prep packets, enabling scalable tracking and analysis of job search activity.
- Implemented relevance classification, TF-IDF semantic similarity, skill gap analysis, and role-aware query generation to reduce noisy job results and surface high-fit opportunities.
- Added Docker, GitHub Actions, unit tests, demo mode, and deployment documentation to present the project as a production-ready data science portfolio application.
